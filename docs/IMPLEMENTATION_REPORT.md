# 実装・検証記録

## 実装

- 全72文法・720問（4/3/3のジャンル順）、検索・級別絞り込み・文法紹介。
- ピンイン付きブロック、タップ追加・取消、300ms長押し、挿入線・プレビュー、途中挿入と回答内移動、画面外ドロップ・キャンセル時の保持。
- 回答語のキーボード／支援技術用「左へ・右へ・戻す」操作。通常の追加・取消はボタンとして操作可能。
- 未完成は採点しない。重複語、簡繁、収録別解、意味逆転のfixturesに対応。
- 解答・全語の品詞と語義・正解／自分の語順比較・中国語読み上げ・速度／音声設定。
- 端末保存、再開、字体切替、初回と復習正解の区別、お気に入り・苦手復習・履歴・検証付きJSON入出力。
- 相対パス、manifest、アイコン、safe area、縮小画面での内部スクロール、原子的なオフラインキャッシュ、明示的な更新。

## 実行した検証

- `python tools/validate_kit.py`: 72文法、720問、3,796トークン、67件の追加別解、素材・ピンイン・両字体の構造検証に合格。
- `npm test`: 15件合格。720問すべての全正解候補、各問5回の初期シャッフル、10件の添付採点fixtures、重複ID、挿入・取消、初回誤答後の復習正解、バックアップ検証。
- `npm run test:browser`: Chromiumで72項目、検索・フィルター、10問完走、解説全語、長押し途中挿入・回答内先頭移動・画面外ドロップ・pointercancel、簡繁切替、リロード復元、初見誤答保持、JSON書き出し・読み込み・破損データ拒否を確認。
- 375×667、390×844、393×852、430×932で最多ブロック問題の採点ボタンが画面内にあり、問題画面の外側スクロールと横はみ出しがないことを確認。
- Service Worker準備後にブラウザをオフラインにしてリロードし、72文法の一覧・別の文法への遷移・問題を確認。キャッシュは教材、画像、UI、全6効果音を含む。
- `/little-mandarin-garden/` のサブディレクトリでも同じブラウザテストに合格。
- `node tests/update.mjs`: 一時ディレクトリで旧版から新版への更新を再現。学習中の適用抑止、明示適用後の新版表示、学習記録保持を確認。

教材の別解は、各文法に対して添付の候補を点検し、模範順を含め全候補を自動テストしました。根拠のない許容語順は追加していません。中国語のあらゆる自然な別解を受理する判定器ではありません。母語話者による第三者校閲は未実施です。
