# 教材の方針と確認範囲

## 範囲
主要文法72項目、720例文。アプリ内の目安はHSK1が22項目、HSK2が24項目、HSK3が26項目。各文法の最初の4問は日常、次の3問はアニメ・漫画を題材にした文、最後の3問は不条理なギャグです。ギャグには、働く猫、真面目なジャガイモ、歌う冷蔵庫などの繰り返し登場する小ネタを使っています。
原文・日本語訳・語の区切り・文法説明・日本語の語義はこの教材用に作成しました。既存の問題集の転載ではありません。

級は**現行HSK2.0の初級を参考にした学習難度の目安**です。公式の全出題文法を一項目ずつ照合して網羅した、あるいは全単語を600語以内に制限した教材ではありません。例えば「反派・冷酷・粉丝・插花」などはテーマを楽しむための発展語です。全ブロックに日本語の意味と声調付きピンインを付け、初学者が読めるようにしています。級による文法の所属は教材によって異なるため、厳密な公式所属として表示しません。

「HSK3級」と「HSK3.0」は別です。このキットは3級までの初級教材を意図し、2026年改訂版HSK3.0の新しい全範囲を網羅したと主張しません。HSK4〜6の追加では、別の教材セットとして `curriculum_basis` と版を明示してください。

## ピンインと文字
普通話の声調記号を使います。一・不の基本的な変調と、よく使う軽声は反映。第三声同士の発音変化は辞書の声調表記を保ちます。儿化は `nǎr / zhèr / diǎnr`。個々の発話で生じる全ての弱化を厳密に転写した音声記号ではありません。
「只」はこの教材では動物の量詞なので **zhī／隻**。「种」は種類では **zhǒng**、育てるときは **zhòng**。「地」は助詞なら **de**、地面なら **dì**。「了」は通常 **le**、来得了の可能補語では **liǎo**。こうした多音字を文脈に合わせて分けています。
繁体字は台湾で一般的な字体を優先して「裡・隻・別・才」などを整えています。字体切替だけで語彙・言い回し・発音体系が台湾華語へローカライズされるわけではありません。両字体のトークンと完成文は一致するよう検証します。

## 解説
各文法に型・使い方・よくある混同を説明。各問題に和訳・文法説明・語順確認の説明・全語の語義と品詞を格納。解答後にはこれらを表示してください。
動詞や形容詞などの分類は初学者向けに簡潔にしています。中国語の形容詞が述語になる点、日本語と品詞が一致しない点に注意してください。一つの語が文中で複数の働きを持つ場合があります。
「看不懂」は `看／不／懂`、「的时候」は `的／时候`。一方で「喜欢」「看起来」「公共汽车」は意味を失うような一文字分解にしません。「的・得・地」は独立ブロックです。

## 正解の幅
模範順に加え、時間を前に置く代表的な別解を格納しています。全ての正しい中国語語順を網羅するものではありません。実装でIDの完全一致だけを比較せず、同一語が入れ替わっても完成文が同じなら受理してください。さらなる妥当な別解は教材版を上げて追加できます。
全問は同じブロックの多重集合を使う問題です。単語を追加・省略する別文や、主客を逆転した意味の違う文は別解にしません。
